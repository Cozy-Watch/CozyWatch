# CozyWatch Github Notifications App

Cozy Watch is a simple GitHub notifications app for developers, designers, and teams who want to stay focused while keeping track of their pull requests.

If you’re tired of missing reviews, searching through endless GitHub emails, or checking tabs just to see if CI passed — Cozy Watch fixes that. It’s a GitHub productivity tool that brings real-time notifications straight to your desktop, so you always know when you’re needed.

The app sits in your macOS menu bar with a clean desktop interface. You can instantly see the status of your pull requests, reviews, and CI/CD builds — all without opening GitHub.

Cozy Watch is completely private and self-contained. It connects only to GitHub, sends no data elsewhere, and keeps your workflow distraction-free.

Stop switching tabs, stop refreshing GitHub, and stop missing updates. Cozy Watch helps you code more, focus better, and stay in control of your GitHub activity.
